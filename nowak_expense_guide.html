Overview

The expense tracking system helps you manage all business expenses, track mileage reimbursements, and generate detailed reports. Key features include:

  • Expense Categories - Organize expenses by type (Fixed, Variable, One-Time)
  • Mileage Tracking - Automatic IRS rate calculations for vehicle reimbursements
  • Proration - Run reports for any date range with automatic daily calculations
  • P&L Integration - Expenses flow into profit & loss reporting

Adding Expenses

Adding a Regular Expense

  1. Go to the Expenses section from the main menu
  2. Click the + Add Expense button
  3. Select the Date of the expense
  4. Choose a Category from the picker (use search to find quickly)
  5. Enter or edit the Description (auto-fills based on category)
  6. Enter the Amount
  7. Click Save Expense
💡 Auto-Fill Descriptions

When you select a category, the description field automatically fills with a default (e.g., "Gas" for Fuel, "Insurance Payment" for Insurance). You can edit this or leave it as-is.

🚗

Mileage Tracking

Mileage is tracked separately and automatically calculated using the IRS standard rate. Mileage entries appear as credits that reduce your net operating expenses.

📍 Current IRS Rate

$0.70 per mile (70 cents) for 2025

Logging Mileage

  1. Go to the Expenses section
  2. Click the 🚗 Log Mileage button
  3. Select the Date
  4. Enter the Miles Driven
  5. The Amount calculates automatically (miles × $0.70)
  6. The Description auto-generates (e.g., "213 miles @ $0.700/mile")
  7. Click Save Mileage
Mileage Reimbursement = Miles Driven × $0.70
Example: 500 miles × $0.70 = $350.00 credit
ℹ️ How Mileage Affects Reports

Mileage appears as a negative amount (credit) in reports. It reduces your total operating expenses to show the true net cost of running the business.

Proration (Partial Month Reporting)

When you run a report for less than a full month, the system automatically prorates fixed expenses to show accurate costs for that period.

How Proration Works

Fixed monthly expenses (like rent, insurance, phone bills) are divided by the number of days in the month, then multiplied by the days in your selected range.

Prorated Amount = (Monthly Amount ÷ Days in Month) × Days in Period

Example: $300 storage for Dec 1-15 (15 days)
= ($300 ÷ 31) × 15 = $145.16
📊 When Proration Applies
  • Fixed expenses - Always prorated for partial periods
  • Variable expenses - Only included if they fall within the date range
  • One-time expenses - Only included if they fall within the date range
  • Mileage - Only included if logged within the date range
⚠️ Important Note

When viewing prorated reports, you'll see both the original amount and the prorated amount in the detail table. Prorated items are marked with a "PRO" badge.

Running Reports

Access expense reports from the Reports section. Several reports include expense data:

📊 Expense Report

Detailed breakdown of all expenses with category analysis, trend charts, and month-over-month comparisons. Use date filters to see specific periods with automatic proration.

📈 P&L Report (Profit & Loss)

Full business performance report including revenue, costs, and expenses. Shows how expenses impact overall profitability.

💰 Cash Flow Report

Tracks money coming in and going out, including expense payments.

📜 Expense History

Historical view of expenses over time with month-by-month trends and category comparisons.

Running an Expense Report

  1. Go to Reports from the main menu
  2. Select Expense Report
  3. Set your From Date and To Date
  4. Optionally filter by Category
  5. Click Run Report
💡 Report Features
  • Click column headers to sort data
  • Trend arrows (↑↓) show month-over-month changes
  • Toggle sections to show/hide charts and tables
  • Print button to generate a paper copy

Best Practices

Daily/Weekly Habits

  • Log mileage daily or at least weekly while trips are fresh in memory
  • Enter expenses promptly when you have receipts
  • Use accurate dates - enter the date the expense occurred, not when you're logging it

Monthly Tasks

  • Enter fixed expenses at the start of each month (rent, insurance, phone)
  • Run the Expense Report at month-end to review spending
  • Check category totals against budget expectations
📱 Mobile Friendly

The system works on your phone! Log mileage and expenses on-the-go right from your mobile browser.
